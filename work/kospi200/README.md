# 🇰🇷 코스피 200 (KOSPI 200) 최근 6개월 고점 대비 폭락주 분석

본 디렉토리는 한국거래소(KRX) 유가증권시장 대표 지수인 **코스피 200(KOSPI 200)** 구성 종목들을 대상으로 최근 6개월간의 주가 데이터를 분석하여, **기간 내 최고가 대비 현재가(또는 최신 종가)가 50% 이상 폭락한 종목을 검색 및 비교 분석**하는 모듈입니다.

---

## 📌 분석 개요

- **대상 지수**: KOSPI 200 Index (한국 대표 제조업, 금융, IT 등 200개 대형 우량 종목)
- **분석 주기/기간**: 현재 기준 최근 6개월 (약 120~126 거래일)
- **핵심 기준**:
  - 최근 6개월 내 일별 최고가(수정고가 기준) 산출
  - 현재가(최신 종가)와 비교하여 **-50% 이상 하락**한 종목 필터링
- **활용 목적**:
  - 대외 변수(금리, 환율, 원자재) 및 업황 사이클 둔화로 인한 낙폭과대 대형주 포착
  - 기술적 과매도 구간 확인 및 중장기 밸류에이션(저PBR/저PER) 매력도 검증
  - 외국인/기관 수급 유입 및 숏커버링 가능성 분석

---

## 📊 세부 분석 지표

| 지표명 | 수식 / 정의 | 의미 |
|---|---|---|
| **6개월 최고가 (High_6M)** | $\max(\text{High}_{t-126 \dots t})$ | 6개월 기간 중 최고 수정주가 |
| **현재가 (Current Price)** | $\text{Close}_t$ | 최신 거래일 종가 |
| **고점 대비 낙폭 (%)** | $\frac{\text{Current Price} - \text{High\_6M}}{\text{High\_6M}} \times 100$ | **-50% 이하** 시 선별 대상 |
| **고점 기록일** | $\arg\max(\text{High})$ 일자 | 하락 추세 지속 기간 확인 |
| **PBR / PER** | 주가순자산비율 / 주가수익비율 | 자산가치 대비 극단적 저평가(PBR < 0.5 등) 여부 |
| **외인/기관 순매수** | 최근 1개월/3개월 누적 순매수 대금 | 바닥권 수급 전환 시그널 확인 |
| **신용잔고율** | 신용융자 잔고 비율 | 반대매매 리스크 및 수급 부담 요인 점검 |

## 🚀 실행 가이드 (스크립트 구현 시)

1. **필수 라이브러리 설치**:
   ```bash
   pip install finance-datareader pykrx pandas numpy tabulate
   ```

2. **코스피 200 종목 코드 수집 및 시세 다운로드**:
   ```bash
   python scripts/fetch_tickers.py
   python scripts/fetch_data.py
   ```

3. **50% 이상 폭락 종목 검색 및 분석 보고서 생성**:
   ```bash
   python scripts/analyze_drop.py --threshold -50
   ```

## ⚠️ 분석 시 유의사항
- **수정주가(Adjusted Price) 적용**: 무상증자, 유상증자 권리락, 액면분할 등으로 인한 주가 왜곡 방지 필수
- **거래정지 및 관리종목 여부**: 감자, 횡령/배임, 회계 이슈 등으로 거래정지 중인 종목 필터링
- **섹터별 하락 특성 고려**: 바이오, 2차전지, 반도체 등 섹터 고유의 변동성 요인과 실적 악화 요인 구분 필요
