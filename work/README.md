# 📉 최근 6개월 고점 대비 50% 이상 폭락 주식 분석 프로젝트

최근 6개월(약 126 거래일) 동안의 주가 데이터를 분석하여, **기간 내 최고가 대비 현재가(또는 최신 종가)가 50% 이상 하락(폭락)한 종목**을 선별하고 비교 분석하는 스킬/프로젝트 워크스페이스입니다.

---

## 🎯 분석 목적
- **과대 낙폭 종목 스크리닝**: 단기 악재, 시장 조정, 펀더멘털 훼손 등으로 6개월 고점 대비 50% 이상 폭락한 종목 자동 발굴
- **시장 간 비교 분석**: 미국 기술주 중심의 **나스닥 100 (NASDAQ 100)** 과 한국 대표 대형주 중심의 **코스피 200 (KOSPI 200)** 종목 간 낙폭 및 회복 탄력성 비교
- **투자 리스크 및 반등 모멘텀 평가**: 단순 낙폭뿐만 아니라 거래량, 기술적 지표(RSI, 이격도), 밸류에이션 지표 등을 함께 평가

## 📐 핵심 분석 로직 및 공식

1. **분석 대상 기간**: 현재 기준 최근 6개월 (T-126 거래일 ~ T)
2. **6개월 최고가 ($High_{6M}$)**: 해당 기간 내 일별 수정고가 중 최댓값
3. **현재가 ($Price_{current}$)**: 가장 최근 거래일의 수정종가
4. **고점 대비 하락률 ($DropRate$)**:
   $$\text{DropRate} = \left( \frac{Price_{current} - High_{6M}}{High_{6M}} \right) \times 100\%$$
5. **필터링 조건**:
   $$\text{DropRate} \le -50\%$$

## 🛠️ 권장 환경 및 라이브러리

- Python 3.9+

- `FinanceDataReader` / `pykrx`: 한국 코스피 200 종목 및 시세 수집
- `pandas`, `numpy`: 시계열 데이터 가공 및 통계 산출
- `matplotlib`, `plotly` (선택): 낙폭 차트 시각화
