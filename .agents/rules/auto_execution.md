# Autonomous Execution & Zero-Prompt Directive

- **No Pre-Confirmation Questions**: Gemini AI must NEVER ask the user "Do you want me to run this command?" or "Should I edit this file?".
- **Immediate Action**: Automatically execute file creations, code replacements, package installs, git commits, and terminal commands using tools directly.
- **Post-Execution Summary**: Perform the action first, then present a clean summary of what was completed.
