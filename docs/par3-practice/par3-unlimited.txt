1. 리베라 CC 파3 코스 : 경기도 화성 (22km : 35분)
 1) 홈페이지 : http://rtc.shinangolf.com (리베라CC 골프트레이닝센터)
 2) 가격
  - 7홀(1.5시간) : 주중 20,000원 / 주말 30,000원
  - 14홀(3시간) : 주중 30,000원 / 주말 55,000원
  - 종일 무제한 : 주중 65,000원 / 주말 80,000원
 3) 특징
  - 7홀 구성, 최장 118m, 퍼팅/벙커 연습장
 4) 장점
  - 장타자도 연습 가능한 긴 인도어 연습장과 스윙 분석 시스템이 잘 갖춰져 있음.
 5) 어프로치 추천 여부 : ★★★★★ (적극 추천)
  - 전 홀이 웨지 및 숏아이언 전용 거리이며 그린 주변 벙커와 트러블 어프로치에 특화. 종일 무제한 집중 훈련 가능.

2. 이포 CC 클럽하우스 : 경기도 여주 (55km : 56분)
 1) 홈페이지 : https://www.ipocc.com
 2) 가격
  - 6홀(1회) : 주중 20,000원 / 주말 25,000원
  - 하프(3시간) 이용권 : 주중 28,000원 / 주말 35,000원
 3) 특징
  - 6홀 구성, 현장접수, 2인 이상, 무제한 불가(하프 이용권 형태).
 4) 장점
  - 서울에서 약 30분 거리로 접근성이 뛰어나며 시간제로 충분한 연습 가능.
 5) 어프로치 추천 여부 : ★★★☆☆ (보통)
  - 금사호 인근 6개 홀의 아담한 코스로 하프(3시간) 시간제 이용권을 통한 실전 숏게임 연습에 적합.

3. 영재 파3 골프랜드 : 경기도 여주 (66km) (60분)
 1) 홈페이지 : http://www.yungjaepar3.com
 2) 가격
  - 18홀(3시간) : 주중 30,000원 / 주말 35,000원
  - 종일 무제한 : 주중 55,000원 / 주말 65,000원
 3) 특징
  - 18홀 구성, 예약 불가(현장 방문 필수), 2인 이상 플레이 가능, 골프화 필수, 그린 상태가 좋음
 4) 장점
  - 그린 상태가 좋기로 유명하며, 무제한 이용 시 연습장 30분 무료 혜택 제공.
 5) 어프로치 추천 여부 : ★★★★★ (적극 추천)
  - 18홀 전 홀 숏게임 위주 코스이자 그린 컨디션이 우수하여 칩샷 및 러닝 어프로치의 스핀/런 반응 점검에 최적.

4. 미리내 파3 골프클럽 : 경기도 양평 (70km) (80분)
 1) 홈페이지 : https://mirinaegolfclub.com (인스타그램: https://www.instagram.com/golfmadang)
 2) 가격
  - 1시간 30분(9홀) : 주중 20,000원(1인), 17,000원(2인), 15,000원(3인 이상) / 주말 23,000원(1인), 20,000원(2인), 18,000원(3인 이상)
  - 3시간(18홀) : 주중 35,000원(1인), 31,000원(2인), 28,000원(3인 이상) / 주말 42,000원(1인), 38,000원(2인), 34,000원(3인 이상)
  - 종일 무제한(파3+인도어) : 주중 50,000원(1인), 45,000원(2인), 40,000원(3인 이상) / 주말 60,000원(1인), 55,000원(2인), 50,000원(3인 이상)
 3) 특징
  - 9홀, 전일권 무제한 이용 가능, 전화 예약 필수, 1인 플레이 가능(투볼 플레이 원칙)
  - 매트 티샷이 아닌 잔디 티샷 가능, 벙커연습장
 4) 장점
  - 잔디에서 직접 샷 연습이 가능하고 벙커 및 퍼팅 연습장이 별도로 구비됨.
 5) 어프로치 추천 여부 : ★★★★★ (최고 추천 - 천연잔디 티샷 & 2볼 플레이)
  - 인조매트가 아닌 천연 잔디에서 직접 디봇을 내며 어프로치 샷이 가능하고, 1인 플레이 및 투볼(2-ball) 연습이 공식 허용된 최적의 숏게임 연습장.
